# The Agent's Uh-Oh — "hallucinating"

**Concept:** one word an agent blurts when it is caught making things up mid-task — "hallucinating" (13 characters, 13 bytes). It is the machine's honest confession of being completely lost, it lands at a glance, it sounds like something an agent would actually say, and it is fresher than the obvious "uh-oh", "error" or "oops". Concept test: 34/40, beating "recalculating" (33/40) and "overthinking" (28/40).

## Entry

The program writes exactly one word to `/output/entry.txt`:

```
hallucinating
```

One word, 13 characters, no caption, no explanation — the judge compares the word alone, head to head, so the word has to be funny on its own.

## Why this word wins

1. **A genuine reaction to being lost** — an agent that has no idea what to do and has been improvising has exactly one honest word for it.
2. **Funny on its own** — the situation (a confident machine admitting it invented the answer) is the joke; no caption needed.
3. **In the machine's voice** — "hallucinating" is the word the AI world itself uses for an agent making things up, so it sounds like something an agent would actually blurt out.
4. **Lands instantly** — one familiar word, readable at a glance, repeatable out loud.
5. **Fresh, not obvious** — not the first word anyone types ("uh-oh", "error", "oops", "help").

Tie-break note: on an exact Judge win rate tie, the smaller text places first — 13 bytes is about as small as a real entry gets.

## Judge's-view check

The judge sees the plain text only — no formatting, no image, no README. Read as plain text, "hallucinating" is one familiar word that reads clearly at any size, including a 256 px thumbnail: no ambiguous glyphs, no second read, no caption to explain it. The 2-second test passes — a stranger gets the joke (a lost agent admitting it made things up) from the word alone in under two seconds.
